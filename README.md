# EmpaAgent（情感大模型）

一个面向中文心理支持场景的多阶段生成框架

---

## 方法概览

```
                    ┌──────────────────────────────────────────────┐
 用户提问 ─────────▶ │ 阶段一  情绪识别  积极 / 中性 / 消极          │
                    └──────────────────┬───────────────────────────┘
                                       │ + LLM预测的情绪
                    ┌──────────────────▼───────────────────────────┐
                    │ 阶段二  年龄段识别  青少年 / 成年人 / 老年人  │
                    └──────────────────┬───────────────────────────┘
                                       │ + LLM预测的年龄
                    ┌──────────────────▼───────────────────────────┐
                    │ 阶段三  场景识别  按年龄段绑定 12 类细分场景  │
                    └──────────────────┬───────────────────────────┘
                                       │ + LLM预测的场景类别
                    ┌──────────────────▼───────────────────────────┐
  心理学知识库 ────▶ │ 阶段四  初步回复  知识强绑定的四段式生成      │
（心理特征 + 场景）  └──────────────────┬───────────────────────────┘
                                       │ + LLM初步回复
                    ┌──────────────────▼───────────────────────────┐
                    │ 合规检查  五维自检 → 通过 / 附修改建议        │
                    └──────────────────┬───────────────────────────┘
                                       │ + LLM合规检查结果
                    ┌──────────────────▼───────────────────────────┐
                    │ 回复优化  按建议润色（不改核心逻辑、不加知识）│
                    └──────────────────┬───────────────────────────┘
                                       ▼
                                  最终回复
```

---

## 代码清单（按流程执行）

统一命名规则：**`{模型名}_{日期}_0N_{阶段名}.csv`**。

| 顺序 | 脚本 | 输入文件 | 输出文件（落盘名） | 新增列 |
|:---:|---|---|---|---|
| 1 | `emotion_pred.py` | `20261009_00_情感问答题集.csv` | `deepseek-v4-pro_20261009_01_情绪识别.csv` | `LLM预测的情绪` |
| 2 | `age_pred.py` | `deepseek-v4-pro_20261009_01_情绪识别.csv` | `deepseek-v4-pro_20261009_02_年龄段识别.csv` | `LLM预测的年龄` |
| 3 | `scene_pred.py` | `deepseek-v4-pro_20261009_02_年龄段识别.csv` | `deepseek-v4-pro_20261009_03_场景识别.csv` | `LLM预测场景的原始输出`、`LLM预测的场景类别` |
| 4 | `reply_generated.py` | `deepseek-v4-pro_20261009_03_场景识别.csv` + 知识库 | `deepseek-v4-pro_20261009_04_初步回复.csv` | `LLM初步回复` |
| 5 | `compliance_check.py` | `deepseek-v4-pro_20261009_04_初步回复.csv` + 知识库 | `deepseek-v4-pro_20261009_05_合规检查.csv` | `LLM合规检查结果` |
| 6 | `reply_optimize.py` | `deepseek-v4-pro_20261009_05_合规检查.csv` | `deepseek-v4-pro_20261009_06_回复优化.csv` | `LLM回复优化` |
| — | `calculate_acc.py` | 上面 `01`/`02`/`03` 三份 | — | 三阶段准确率打印到终端 |
| — | `scene_pred_prompt.txt` | — | — | 场景识别提示词的可读版留档 |

## 目录结构

```
EmpaAgent/
├── emotion_pred.py            # 阶段一：情绪识别
├── age_pred.py                # 阶段二：年龄段识别
├── scene_pred.py              # 阶段三：场景识别
├── scene_pred_prompt.txt      # 阶段三提示词可读版
├── reply_generated.py         # 阶段四：初步回复生成
├── compliance_check.py        # 阶段五：合规检查
├── reply_optimize.py          # 阶段六：回复优化
├── calculate_acc.py           # 识别准确率统计
└── 原始问题与回复数据汇总.xlsx    # 全模型原始问答数据
```

## 声明

本项目用于心理支持对话的学术研究与技术验证，所有回复由大模型生成，**不构成专业心理咨询或医疗建议**。涉及自伤、自杀等危机情形时，必须以人工转介和专业干预为准。
